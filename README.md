# NOVA Sneakers · Presentación comercial

Presentación web del proyecto intermodular NOVA Sneakers (2.º DAM): una tienda online de zapatillas
y el sistema que la hace funcionar. Hecha por Omar, Álvaro y Berme.

**Verla:** https://omar1676.github.io/nova-sneakers-presentacion/

Se pasa de una diapositiva a otra deslizando hacia arriba (dedo, rueda del ratón o panel táctil),
con las flechas del teclado o con el carril de puntos de la derecha. F: pantalla completa · I: índice.
En el móvil, mejor en horizontal.

Las capturas son del proyecto funcionando en un entorno de prueba: los datos y las compras que
aparecen son de prueba, no ventas reales.
