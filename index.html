servidor-admin/consultas-tienda.js · crearCompra() y confirmarCompra() · líneas 76–87

76// Crea el pedido PENDIENTE (crear_compra_web): devuelve su id
77async function crearCompra(cliente, idCliente, referencia, skus, cantidades, telefono, direccion) {
78  const resultado = await cliente.query(
79    'SELECT public.crear_compra_web($1, $2, $3::int[], $4::int[], $5, $6) AS id',
80    [idCliente, referencia, skus, cantidades, telefono || null, direccion]);
81  return resultado.rows[0].id;
82}
83
84// Pago aceptado: confirmado y pagado (el trigger descuenta el stock)
85async function confirmarCompra(cliente, idCliente, idPedido) {
86  await cliente.query('SELECT public.confirmar_compra_web($1, $2)', [idCliente, idPedido]);
87}

Qué hace. El servidor no escribe en las tablas: llama a funciones de PostgreSQL y pasa los datos como parámetros ($1, $2…), nunca pegados al SQL.

Para qué sirve. Crear el pedido pendiente (paso 3 de la compra) y confirmarlo cuando se acepta el pago simulado (paso 4).

03_triggers.sql · líneas 33–38  y  02_funciones.sql · descontar_stock_confirmacion() · líneas 500–511

33CREATE TRIGGER trg_descontar_stock_confirmacion
34AFTER UPDATE OF estado
35ON public.pedidos
36FOR EACH ROW
37WHEN (NEW.estado = 'confirmado' AND OLD.estado <> 'confirmado')
38EXECUTE FUNCTION descontar_stock_confirmacion();
                                     ···
500    LOOP
501        -- Si falta stock, descontar_stock da error y el pedido no se confirma
502        PERFORM public.descontar_stock(
503            linea.id_producto_sku,
504            linea.id_nave,
505            linea.cantidad
506        );
507
508        -- La marca evita descontar otra vez si el pedido se vuelve a confirmar
509        UPDATE public.linea_pedido
510        SET stock_descontado = true
511        WHERE id_linea = linea.id_linea;

Qué hace. Cuando un pedido pasa a «confirmado», el trigger recorre sus líneas y resta cada talla del almacén. Si falta stock, da error y el pedido no se confirma.

Para qué sirve. Que la tienda nunca venda un par que no existe y que confirmar dos veces no reste dos veces.

04_Python/modulos/prediccion.py · demanda_mensual() · líneas 23–28

23    pares = demanda.groupby(["nombre_modelo", "mes"])["cantidad"].sum()
24    meses = pd.period_range(demanda["mes"].min(), demanda["mes"].max(), freq="M")

Qué hace. Suma los pares pedidos de cada modelo en cada mes y rellena con 0 los meses sin pedidos, para que la serie no tenga huecos.

Para qué sirve. Es la tabla con la que el dashboard entrena y compara el baseline y la regresión de la pestaña Predicción.
